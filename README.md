# Security Incident Report Manager

Creates, lists, and updates security incident reports. Data is stored in a local JSON file for the lab demo.

## Technology
- Node.js, Express.js, HTML, CSS, JavaScript
- JSON file storage where applicable

## Run
1. Install Node.js LTS.
2. Open a terminal in this folder.
3. Run `npm install`
4. Run `npm start`
5. Open http://localhost:3000

## API
See the form and endpoints in `server.js`. This is a beginner educational project, not a production security service.
